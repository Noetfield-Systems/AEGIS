# AEGIS 30-Day Evidence + Product Pilot (operational blueprint)
Window: 2026-11-12 to 2026-12-11. Application target Dec 18 before official Dec 22 deadline.

## Week 1 / days 1–7: baseline + eligibility
Verify bidder eligibility, corporate docs, Canadian payroll/FTE/location & amendments; audit existing code SHA, deployed services and source evidence; test public demo; 2–3 buyer problem interviews; document current manual process; independent initial scorecard with no invented points.
Exit: source-index manifest + eligible-company dossier + task owner/due + 1 observed buyer issue.

## Week 2 / days 8–14: native evaluator + obligation graph
Version five Canadian policy sources, build five-state mapping, direct data/model/output native tests and negative fixtures, implement event snapshots and focused baseline metrics.
Exit: reproducible test run & labelled fixtures with independent reviewer.

## Week 3 / days 15–21: historical replay + workflow
Policy-change before/after comparison, affected-system precision/recall, replay of completed assessments, review/annotate and notify in-flight/new tasks. Prove interoperability on three documented surfaces, tenant-negative access tests, retention/export/deletion checks.
Exit: real replay video, hashes, independent QA results, no false MET.

## Week 4 / days 22–30: benchmark + market + bid
Blind review against spreadsheet/manual and permitted commercial competitor trials; confidence intervals; named/signed specialist capacity; defined 18–20-month project scope, cost ledger; at least 5–8 total documented interviews and two bounded paid-pilot offers; mock hostile scoring; draft evidence package.
Exit: internal verdict with all 10 gates, documentary evidence, price validation, operator release receipt.
Missing mandatory evidence = not-ready; choose a compliant partner only if it supplies genuinely integrated proof, not for ceremonial inclusion.

## Product release lanes
L0: existing private cockpit; Tabler-backed EN/FR-only design system with persistent Dark/Light/System.
L1: evidence APIs, explicit audit, encrypted storage and backup, signed internal review.
L2: native evaluator & replay proof (sell 3–5-system pilot).
L3: multi-tenant / enterprise controls, EN/FR customer edition, verified adapters and SLAs.
L4: subscriptions, partner programs, international policy packs and community.
Each lane must pass test/QA and real-user acceptance; higher lanes are not yet delivered.
